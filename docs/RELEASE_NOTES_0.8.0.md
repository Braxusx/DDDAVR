# Dragon's Dogma: Dark Arisen VR 0.8.0

First public release. Steam and GOG.

- Native stereo rendering with head tracking around the third-person camera
- NVIDIA DLSS / DLAA (DLAA, Ultra Quality, Quality, Balanced, Performance, Ultra Performance; presets K / J / M / L)
- Optional DXVK with an in-headset "Building shader cache" notice
- Distance Scaling: Game Default, 2X (performance impact), 3X (extreme performance impact)
- HUD panel; world-placed quest markers, pawn name tags and enemy bars; NPC dialogue size; stereo cutscene subtitles; white bow reticle
- Sun shafts and lens flare off by default (optional); reduced sun glare made from the player's own game files
- Launcher: Steam / GOG detection, install / update / uninstall (keeps an existing d3d9.dll such as ReShade as a backup), settings, OpenXR runtime check, desktop shortcut, log collection

Release zip: `DragonsDogmaVR-Launcher_0.8.0.exe`, `manual_install/`, `licenses/`, `README.txt`.
